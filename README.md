# 🛒 Online Shopping System - Python OOPs

A simple console-based shopping cart system built using Python Object-Oriented Programming concepts.

### ✨ Features
- Add products to cart
- View cart with total bill calculation
- Remove products from cart
- Checkout system

### 💻 OOPs Concepts Used
- Class & Object (Product, Cart classes)
- Encapsulation (private cart items)
- Composition (Cart contains Product objects)
- Methods & Constructor

### ▶️ How to Run
python online_shopping.py
